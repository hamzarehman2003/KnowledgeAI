# KnowledgeAI

## Overview

KnowledgeAI is an AI-powered document assistant that enables users to upload documents and ask natural language questions.

The system retrieves relevant information from the uploaded documents using Retrieval-Augmented Generation (RAG) and generates accurate responses with citations.

## Target Users

- Businesses
- Students
- Researchers
- Legal firms
- Healthcare organizations

## MVP Features

- User authentication
- PDF upload
- Document processing
- AI-powered chat
- Source citations

## Technology Stack

- Next.js
- FastAPI
- PostgreSQL
- ChromaDB
- Ollama (Qwen)
- Docker
